# 使用说明

## 基本操作

### 浏览文档

1. 点击侧边栏中的文档标题即可打开文档
2. 文档会在主内容区域显示
3. 支持多个文档快速切换

### 阅读位置记忆

1. 切走再切回同一篇文档，会回到上次读到的位置
2. 位置存在浏览器本地，下次打开仍然有效
3. 距顶部不到 200px 时会清掉该文档的记录（视为"从头读"）
4. 从搜索结果进入时以命中处为准，不恢复历史位置

### 搜索文档

搜索是全文检索：正文、标题、路径一起匹配。

1. 点击侧边栏上方的搜索框，输入关键词
2. 侧边栏实时列出命中的文档，每条给出命中片段，关键词高亮
3. 同一篇里出现多次会标出「命中 N 次」
4. 点击结果会打开该文档，并自动滚到正文里第一处命中，所有命中都标出来
5. 清空搜索框或按 Esc 恢复完整目录树，正文里的标记随之撤掉

### 切换主题

1. 点击侧边栏底部的太阳/月亮图标
2. 主题偏好会自动保存到本地
3. 下次访问自动应用

### 展开/收起侧边栏

1. 点击侧边栏底部的折叠按钮
2. 侧边栏收起后按钮会移到左侧，其中搜索按钮可直接展开侧边栏并把光标放进搜索框
3. 再次点击可展开

侧边栏展开时，顶部（搜索框）与底部（按钮）固定不动，只有中间的文档列表滚动。

## 文档格式

### 支持的格式

| 格式 | 说明 | 文件扩展名 |
|------|------|-----------|
| TXT | 纯文本，支持 Markdown 语法 | .txt |
| Markdown | 标记语言 | .md |
| Word | Word 文档 | .docx |

### Markdown 语法

#### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

#### 列表

```markdown
- 无序列表项
- 无序列表项

1. 有序列表项
2. 有序列表项
```

#### 代码块

```python
def hello():
    print("Hello, World!")
```

#### 表格

```markdown
| 列1 | 列2 |
|-----|-----|
| 内容1 | 内容2 |
```

#### Mermaid 图表

```mermaid
graph TD
    A[开始] --> B[处理]
    B --> C[结束]
```

## 快捷键

| 快捷键 | 功能 |
|-------|------|
| Enter | 在搜索框中打开第一条命中 |
| Esc | 在搜索框中清空搜索 |
| Home / End | 浏览器默认行为：跳到页面顶部 / 底部 |

## 常见问题

- **文档不显示**：检查文档是否在 txt 目录下
- **样式异常**：尝试清除浏览器缓存
- **搜索无结果**：确认搜索功能已启用

## 进阶使用

### 设置首页

在 `reader/config.json` 中设置 `home_page` 为指定文档文件名。

### 排除文件

使用 `exclude_patterns` 和 `exclude_files` 排除不需要的目录或文件。
